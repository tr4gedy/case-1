Требования:
 * .Net 8.0 SDK
 * Visual Studio 2022

Сборка и запуск:
 * Клонируйте репозиторий или скачайте с самого гитхаба проект
 * Восстановите NuGet-пакеты с помощью команды dotnet restore
 * Соберите решение в визуал студио с помощью кнопки внутри решения или с помощью команды dontet build

Ответы на вопросы:
 1. Управление состоянием: Как вы реализовали автоматическое обновление статуса
курса? Где находится эта логика и почему вы выбрали именно такое место?
Статус обновляется через свойство Status в модели Course, который зависит от Progress. Было выбрано такое место из-за отношения статуса к курсу, что повышает читаемость кода.

 3. Валидация URL: Как организована проверка валидности ссылок на учебные
материалы? Какие подходы к валидации URL вы рассматривали?
Организована проверка валидности с помощью класса Uri и его методов. Рассматривал валидацию через регулярные выражения, но выбрал класс Uri из-за его надежности и удобства. 

 5. Пользовательский опыт: Какие визуальные элементы вы добавили для удобного
отслеживания прогресса? Как реализована цветовая индикация статусов и
прогресса?
Был добавлен ProgressBar с цветовым индикатором (0% - сервый, между 0% и 100% - синий, 100% - фиолетовый). Через простой Background и триггеры была реализована цветовая индикация статуса и прогресса. 

 7. Архитектура расширения: Если бы потребовалось добавить систему
напоминаний о необходимости продолжить обучение, как бы вы интегрировали эту
функциональность в текущую архитектуру?
Добавил бы модели для напоминания (Reminder) и соотвествующие ему сервисы, также расширил бы MainWindow, чтобы показывалось уведомление, либо же создал бы совершенно новое окно, чтобы уже оно выскакивало в качестве уведомления.

Тажке из-за невозможности записать видео на компьютере будут предоставлены лишь скриншоты работы программы
